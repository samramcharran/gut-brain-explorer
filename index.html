About This Project

The Gut-Brain Axis

The gut-brain axis is a bidirectional communication network linking the central nervous system with the enteric nervous system of the gastrointestinal tract. Trillions of bacteria in our gut produce neurotransmitters, metabolites, and immune signals that influence our brain and behavior.

Data Sources

  • BugSigDB - Curated database of published microbiome signatures (CC0 license)
  • PubMed - Recent gut-brain axis research papers
  • Review Literature - Meta-analyses and systematic reviews on diet-microbiome relationships

Technical Implementation

Data Pipeline: Python scripts fetch and normalize data from public APIs, transforming raw research data into clean JSON for visualization.

Frontend: Static HTML/CSS/JavaScript with Chart.js for interactive visualizations. No build step required - just data engineering meets web accessibility.

Why GutBrain Explorer?

I built this project to demonstrate my passion for making complex biological data accessible to everyone. The gut-brain axis represents one of the most exciting frontiers in understanding human health - and I believe tools that help people explore this connection can empower better health decisions.
